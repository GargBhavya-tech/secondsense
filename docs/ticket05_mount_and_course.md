# Ticket #5 — Mount + Demo Course Prepped (pre-event)

**Phase 0 · Pre-event · Prototype · Must-build before doors open**

## Chest mount
- [ ] Lanyard / chest strap that holds the phone **camera chest-forward and steady**
- [ ] Test: wear it, walk 10 steps, camera stays forward and level **with no hand support**
- Why: arm-swing from a handheld phone breaks depth mapping — mount, don't hold. The chest
  position is the entire cane-blind-spot argument; don't compromise it.

## High-contrast demo course (build the physical props)
- [ ] **Dark chair on light floor** (obstacle avoidance)
- [ ] **Head-height obstacle rig** (the cane-blind-spot beat — something to duck/stop for)
- [ ] **Taped "curb / drop-off" line** (negative-obstacle detection)
- [ ] **Marked "door"** (the "find the door" voice-search climax)
- [ ] Keep one **separate, never-walked** layout aside for the held-out metrics run (#38)

**Done when:** the mount is stable hands-free and all four course elements exist physically,
with a spare untouched layout reserved for held-out testing.
